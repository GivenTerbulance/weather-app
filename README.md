# 🌤️ Weather Forecast GUI App

A simple and elegant **Python GUI application** that fetches and displays real-time weather information using the **OpenWeatherMap API**. Built with `Tkinter` and `Pillow`, it allows users to input any city and get weather updates including temperature, humidity, coordinates, and more.

---

## 🚀 Features

- Real-time weather updates for any city
- Current temperature, humidity, min/max temperatures
- City and country info with geographic coordinates
- Dynamic icons for day/night (e.g., sun/moon)
- Date and time display
- Simple and intuitive Tkinter-based interface
- Background and weather icons (customizable)

---

## 🛠️ Technologies Used

- Python 3.x
- Tkinter (for GUI)
- Requests (to access OpenWeatherMap API)
- Pillow (PIL) for image handling
